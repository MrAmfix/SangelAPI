# SangelAPI

**SangelAPI** — серверная часть стартапа **Sangel**.  
Проект был направлен на повышение личной безопасности девушек в городе с помощью Android-приложения и Bluetooth-устройств-украшений.

---

## 📌 О проекте

Идея стартапа заключалась в создании системы быстрого оповещения близких людей о возможной опасности.  
Пользователь носит небольшое Bluetooth-устройство, связанное с приложением. В случае угрозы достаточно нажать кнопку на устройстве — и приложение отправит избранным контактам SMS с координатами владельца или вызовет ГБР.  

Дополнительные возможности приложения:  
- определение доступных Bluetooth-устройств и их повторное появление в эфире (сигнал тревоги),  
- отправка геолокации доверенным контактам при тревоге,  
- отображение местоположения других пользователей приложения (если включена функция в настройках приватности).
- возможность платного вызова группы быстрого реагирования для обеспечения безопасности пользователя
